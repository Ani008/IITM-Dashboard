# IITM Dashboard

A full-stack application with a React frontend and a Node.js/Express backend.

## Getting Started

### 1. Clone the Repository
Open your terminal and run:
```bash
git clone <your-repo-url>
cd "IITM Dashboard"
```

### 2. Install Dependencies
You need to install packages in both the frontend and backend directories.
```bash
npm install
```

### 3. Initialize Database
Run the seed script one time to initialize the users and default data.
```bash
node seed.js
```

### 4. Running the Application
You will need to run the backend and frontend simultaneously in separate terminal windows.
Terminal 1 (Backend):
```bash
node server.js
```
Terminal 2 (Frontend):
```bash
npm run dev
```
